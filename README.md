A single pickup line, spoken by a vending machine to a passing human, for the
[One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) on make.fun.

## The line

> Hey gorgeous, I don't light up for just anyone — but you pressed all my buttons, so exact change is on the house if you'll stay.

128 characters, one line, well inside the 200-character gate. The machine
flirts the only way it knows how: with its lights, its buttons, and its
exact change — and the punch lands on the last few words.

## How it works

`main.py` (pure Python stdlib) validates the line against the gate —
1–200 characters, a single line, not blank — and writes it to
`/output/entry.txt`:

```sh
python3 main.py
```
